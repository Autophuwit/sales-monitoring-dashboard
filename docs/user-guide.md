# User guide

Open the site link → log in with your email (a 6-digit code is sent to you) → the home page opens the **desktop** or
**mobile** layout for your screen. You can force one with the Auto / Desktop / Mobile switch (remembered on that device).
On a phone: browser **Share → Add to Home Screen** to open it like an app.

## Which dashboard answers what

| Question | Dashboard | Where |
|---|---|---|
| Are we on track for the month? | Overall Performance | GA / M1 run rate, % Achieve, gap to target |
| Is this week better than last week? | Overall Performance | Weekly tables (%WoW), current week card |
| Which areas are falling? | Overall Performance | Sub-district → store table (sorted by change), %MoM map |
| Which customer segments are working? | Overall Performance | Shops by Segment map — click a segment to filter |
| Which areas need which action? | Overall Performance | ARPU × GA quadrant chart |
| Are the game plans delivering their commitment? | Gameplan Monitoring | Plan table by channel: GA RR vs. commit, %Commit |
| Which SIM types / stores drag a plan down? | Gameplan Monitoring | Click a plan → SIM type and store tables follow |
| Will we hit the daily commit? | Gameplan Monitoring | Daily chart vs. commit line |
| How is one store doing, and should I worry? | Data By Store | Pick the store: target, priority, plans, alert vs. zone peers |

## Filtering

- **Slicers** (top of page): multi-select with search. Options narrow to what is possible with the other slicers.
- **Month**: the latest month you pick is "current", the one before it "previous". Past months are complete months.
- **Click to filter**: click a table row, a map bubble, a bar or a chart line → the whole page filters to it.
  The clicked chart stays complete and highlights your pick.
  - **Ctrl+click** (phone: **long-press**) to add more. Picks in the same chart = *either*; picks in different charts = *both*.
  - Click the same item again, press **✕** on the blue chip, click empty space in a chart, or **Clear filters** to undo.
- **Channel**: 7-11, RTR or Other (codes in the area that are in neither store profile).

## Reading the numbers

- **Run rate (RR)** = this month so far, projected to a full month. See [metrics](metrics.md) for every formula.
- **Week values** are 7-day values, so a short or long week 4 compares fairly.
- Colours: green = up, red = down; in plan and store tables the bar behind a % shows its size.
- The **AS of** date at the top is the latest day in the data.
